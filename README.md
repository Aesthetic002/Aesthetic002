<details>
<summary><b>🤖 AI-Driven SDN Traffic Controller</b> — Jun 2026</summary>
<br>

`Python` · `Ryu` · `OpenFlow` · `Mininet` · `PyTorch` · `Open vSwitch`

Architected an AI-driven SDN traffic controller using Ryu, OpenFlow, and a Dueling LSTM-DQN reinforcement learning agent, dynamically routing IoT traffic (sensor, video, elephant flows) across a simulated Mininet + Open vSwitch network. Engineered a 20-feature state representation and a multi-objective reward function (latency, reliability, throughput, fairness) to prioritize emergency traffic and avoid congestion in real time.

<details>
<summary><b>🧠 Second Brain — AI Knowledge Management System</b> — Jun 2026</summary>
<br>

`Next.js` · `FastAPI` · `PostgreSQL` · `pgvector` · `Elasticsearch` · `D3.js` · `LangChain`

An AI-native personal knowledge management system that auto-classifies, tags, and summarizes uploaded files, links, and notes via an LLM pipeline (Claude, RAG), organizing content into a semantic folder hierarchy. Features a real-time, force-directed knowledge graph (D3.js) and a RAG chat assistant over PostgreSQL/pgvector embeddings and Elasticsearch, enabling natural-language queries with cited sources.

</details>
